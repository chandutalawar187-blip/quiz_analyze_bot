Faculty password management

Issue or reset a faculty member's app password. Enter their Discord user ID; a one-time password will be generated and shown only once. They must change it after signing in.


Copy this password and send it securely to the faculty member. It will not be shown again.

Access requirement: The member must be in this server and have its configured Faculty role. Resetting a password invalidates the previous one.
