Quizcord Analytics

Privacy Policy

Effective date: October 18, 2026

This policy explains how the Quizcord Analytics Discord application and dashboard (the “Service”) process information when a Discord server installs or uses the Service.

Information processed

  • Server and member information: Discord server and channel IDs, server names, member Discord IDs, account usernames, display names, and server nicknames. The bot synchronizes human member information to provide server-specific dashboards and student matching.
  • Student mappings: identifiers such as USNs, student names, and optional Quizcord leaderboard usernames that a server administrator or authorized faculty member enters or manages.
  • Quiz analytics: Quizcord quiz IDs, start/completion times, leaderboard participant identifiers, ranks and points, and attendance-related records. Points are Quizcord leaderboard points, not a verified count of correct answers.
  • Faculty access data: faculty Discord IDs, server role settings, student assignments, and salted password hashes with security counters. App passwords are not stored in plaintext.
  • Dashboard sign-in data: Discord identity and server information requested through OAuth to authenticate users and check their access. The Service does not request Discord account passwords.
  • Security checks: faculty password sign-in uses Cloudflare Turnstile, which may process technical and device information under Cloudflare’s own privacy terms.

How information is used

Information is used to collect and display server-specific quiz analytics, match leaderboard participants to student records, provide faculty and administrator access, deliver relevant bot responses, and protect the Service from abuse. Server records are scoped so dashboard users can access only servers where their Discord permissions or configured faculty role authorize them.

Storage, service providers, and sharing

The Service database is hosted on Railway and stores records separately by Discord server. Discord provides the bot, OAuth, and server data APIs. Cloudflare provides the Turnstile security challenge. If Sentry monitoring is enabled by the Service operator, Sentry receives error reports, sampled performance traces and profiles, sanitized warning-and-higher logs, and dashboard request-count and duration metrics. This may include technical runtime information, exception messages and stack traces, endpoint operation names, and timing data. The Service removes HTTP request details, request bodies, and breadcrumbs from events; log messages are replaced with generic severity labels, and log attributes are limited to safe code/logger metadata. Metrics use route templates rather than concrete URLs. Exception messages or stack traces may still contain information produced by the application. These providers process information as needed to deliver their services and are subject to their own terms and privacy policies. The Service operator does not sell personal information.

Retention and deletion

Server analytics and configuration are retained in the Service database. When the bot leaves a server, that server is marked inactive; this does not automatically delete its stored records. A server owner may request deletion by emailing chandutalawar187@gmail.com from an address they control and identifying the Discord server. Requests will be reviewed and handled by the Service operator. Some information may remain where required for security, legal, or operational reasons.

Security

The Service uses access checks, HTTPS for the hosted dashboard, password hashing, and request limits. No internet service can guarantee absolute security. Do not enter information that your organization is not authorized to share with this Service.

Children and sensitive information

The Service is intended for server administrators, faculty, and quiz participants in communities that choose to install it. Do not use it to store highly sensitive personal information. Server owners are responsible for ensuring they have appropriate authority and notices before entering student information.

Changes and contact

This policy may be updated as the Service changes. Questions or requests about information handled by the Service can be sent to chandutalawar187@gmail.com.
